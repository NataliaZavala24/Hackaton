# Gestor de Finanzas Personales

## Autores

- Palomeque Agustín Nicolás
- Zavala Mónica Natalia

## Descripción

Aplicación web interactiva que permite gestionar las finanzas personales mediante el registro y visualización de ingresos y gastos.

El proyecto fue desarrollado como parte de una actividad académica, aplicando conceptos de Programación Orientada a Objetos (POO), JavaScript, manipulación del DOM, almacenamiento local de datos y visualización gráfica de información financiera.

---

## Funcionalidades

- Registrar ingresos y gastos.
- Registrar fecha de cada movimiento.
- Clasificar las transacciones por categorías.
- Visualizar el historial completo de movimientos.
- Calcular ingresos, gastos y balance total.
- Mostrar un gráfico de barras agrupado por categorías.
- Mostrar un gráfico de líneas con la evolución temporal de ingresos, gastos y balance neto.
- Eliminar transacciones individuales.
- Eliminar todo el historial de movimientos.
- Validar los datos ingresados por el usuario.
- Mostrar mensajes interactivos mediante SweetAlert2.
- Guardar los datos utilizando localStorage para conservar la información al actualizar o cerrar la página.

---

## Tecnologías utilizadas

- HTML5
- JavaScript (ES6)
- Tailwind CSS
- ApexCharts
- SweetAlert2
- localStorage
